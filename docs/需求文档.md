## 1 业务背景与痛点

### 1.1 医疗场景
设备持续产生患者相关影像（DICOM、原始图等），可能关联姓名、证件号、检查号等敏感信息。用户需要：
- 磁盘不满，检查不因存图失败中断  
- 关键影像按制度留存，可备份、可恢复、可审计  
- 对外导出或跨机构拷贝前可做隐私处理  
- 操作可追溯，满足院内检查与纠纷调阅  

### 1.2 工业视觉场景
产线 7×24 小时采集原图、NG 图、指纹等大文件，写入并发高。用户需要：
- SSD 中转削峰，避免直接打满归档盘导致丢帧、卡顿  
- 磁盘水位可控，防止满盘停线  
- 按项目/批次/NG 等策略管理生命周期  
- 质检原图与元数据可追溯、可导出复盘  

### 1.3 现有痛点

| 痛点 | 影响 |
|------|------|
| 高并发直写大容量慢盘 | 丢帧、采集卡顿 |
| 无分级清理 / 无保护 | 满盘停机，或误删未归档、采集中数据 |
| 无可靠自动备份 | 硬盘损坏导致不可恢复 |
| 无完整操作记录 | 合规与事故复盘缺少依据 |
| 中转/归档/备份策略不统一 | 隐私与篡改风险、依赖人工 |
| 现有产品清理粗放 | 仅按日期循环删除，无优先级、无数据类型划分 |

## 2 总体用户需求

1. **无人值守**：后台静默完成监控、分级清理、中转迁移、按策略备份。  
2. **多存储分区独立管控**：至少区分 **SSD 中转、长期归档、本地备份、网络/NAS 备份**（可裁剪启用）。  
3. **数据全生命周期治理**：分类标记 → 加密存储 → 分级清理（P0–P3）→ 备份/审计。  
4. **模式可切换**：医疗模式与工业模式，默认参数与强制项不同。  
5. **全配置化 + 可远程管理**：路径、阈值、周期、端口等可配；提供管理接口。  
6. **高可用体验**：单盘离线、网络中断、单文件失败时以告警为主，**守护进程不整体退出**；重启后接续未完成的中转/备份。  
7. **日志与审计分离**：运行日志可滚动；审计日志长期保留、防普通清理误删。  
8. **国产化与 Windows 双栈**：同一套需求在 Windows 与麒麟上均可部署。

## 4 功能需求

### 4.1 磁盘数据分类与标记

**目标**：为自动/手动清理提供统一分类与优先级基础。

| 编号 | 需求描述 |
|------|----------|
| R07001 | 建立统一数据分类，至少包括：临床影像数据、日志数据、临时缓存与队列数据；支持扩展。 |
| R07002 | 本地存储数据划分清理优先级，至少： **P0 禁止清理**、**P1 延迟清理**、**P2 正常清理**、**P3 优先回收**。 |
| R07003 | 分类标记项清单至少包含（可与优先级映射，支持扩展）： |

**分类项与建议优先级映射（可配置，下列为默认建议）**

| 分类项 | 建议优先级 |
|--------|------------|
| 正在采集中的图像 | P0（强制） |
| 未归档的图像 | P0（强制） |
| 用户主动锁定的检查（该检查下全部图像） | P0（强制） |
| 存储确认未完成图像（若启用） | P0 |
| 存储确认已完成图像（若启用） | 可配 |
| 已归档但诊断报告未关联（待诊断） | P1 |
| 已归档且诊断报告已关联（已诊断） | P2 |
| 近期有调阅检查（默认 15 天，ini 可配） | P1 |
| 已拒绝 / 已打印 / 已导出的图像 | P2 或按策略 |
| 未过保护期的回收站数据 | 按保护策略 |
| 已过保护期的回收站数据 | P2/P3 |
| 过期无效缓存、不影响功能的临时文件、队列残留 | P3 |
| 软件日志（默认最低保留半年） | 受保护，不进普通 P3 误删 |
| 审计日志（默认最低保留 1 年） | **禁止普通清理删除** |
| Windows 事件日志等（默认最低保留半年） | 受保护策略约束 |

**优先级含义（与 PRD 对齐）**
- **P0**：禁止自动清理（采集中、未发 PACS、存储确认未完成、用户锁定等）  
- **P1**：延迟清理（已归档未关联报告、近期调阅等）  
- **P2**：正常清理（已归档已关联报告、存储确认成功、过期回收站等）  
- **P3**：优先回收（临时文件、队列残留等）

### 4.2 磁盘数据加密与密钥管理

| 编号 | 需求描述 |
|------|----------|
| R07004 | 患者影像等支持静态加密存储；写入磁盘时自动加密；采用 AES-256 或更高强度（医疗场景宜支持国密算法选项）；密钥不得与影像同物理位置或明文配置存放。 |
| R07005 | 文件被复制到系统外后，未授权条件下不可解读原始业务数据；解密须经系统鉴权或授权密钥恢复流程，禁止仅以私有格式混淆替代。 |
| R07006 | 数据库敏感字段保护：用户密码（不可逆加盐哈希）；Token/密钥/密码资料、外部系统凭据（可逆加密）；患者敏感标识（按策略）。 |
| R07007 | 密钥生命周期：生成、安全存储、定期更新、轮换、备份与吊销；密钥模块独立于业务数据；密钥操作全部记审计。 |

工业模式：静态加密与国密可为可选项；医疗模式：归档/备份静态加密与密钥分离为默认或强制可配置项。

### 4.3 磁盘清理策略配置

| 编号 | 需求描述 |
|------|----------|
| R07008 | 提供统一清理优先级映射：授权用户可将分类标记分配至 P0–P3（可调整顺序）；系统按配置自动或手动释放空间。 |
| R07009 | 支持两种触发方式，终止条件统一按策略执行： |

**触发方式**
- **自动**：磁盘使用率达阈值（如 90%）；或按日/周/月定时（可设执行时段，默认凌晨 3:00）  
- **手动**：用户通过界面发起，遵循同一优先级顺序与终止条件  

| 编号 | 需求描述 |
|------|----------|
| R07010 | 终止条件可配置： |
| | • **按时间终止**：保留最近 N 天/月数据；从 P3 起清，遇到时间保护范围内数据则跳过，满足时间条件后结束 |
| | • **按容量终止**：清理至剩余空间达目标（如剩余 20% 或不少于 10 GB）；每批后重评估，满足即停 |
| R07011 | 执行顺序严格：必须 **P3 → P2 → P1**，不可跳跃；同优先级内建议按时间从旧到新。终止条件达成后**不得**进入更高优先级。P0 永不进入自动清理。 |

另需满足 IDS 要求：未完成中转/归档的文件不因“过期规则”被误删；用户标记永久保留的不参与自动删除。

### 4.4 磁盘清理执行与保护

| 编号 | 需求描述 |
|------|----------|
| R07012 | 手动清理：执行前风险确认对话框（永久删除、不可恢复），需输入确认短语（如“确认清理”）；过程中显示进度，允许中止。 |
| R07013 | 首次启用自动清理：不可跳过的风险提示；用户勾选“已知晓上述风险”后方可保存策略或执行；配置变更记入审计。 |
| R07014 | 自动清理进程：低 I/O 优先级；检测到采集、图像后处理等高实时任务时暂停或拉长间隔；例如到达定时点但软件忙，则停止，待无动作约 15 分钟后再执行。清理不得显著抢占采集写入带宽。 |
| — | 删除前写审计：业务 ID/路径、项目、大小、时间、删除原因、操作来源（自动/手动/账号）。 |
| — | 可识别并清理明确无用的空文件、损坏占位文件，并单独记日志。 |

### 4.5 磁盘空间监控与告警

| 编号 | 需求描述 |
|------|----------|
| R07015 | 磁盘空间与健康监控： |
| | • 可配置使用率阈值（如 90%）；达阈值弹窗告警；阈值需保证**绝对预留不低于 5 GB** |
| | • 已开启自动清理时：按规则执行；清理后仍不满足阈值（如仅剩 P0 仍超阈）须告警 |
| | • **剩余不足 5 GB**：弹窗告警并**禁用图像采集**，提示清理或转移；**保留全部日志记录能力** |
| R07016 | 监控磁盘 SMART 等健康指标；预测硬件故障风险时告警，提示尽快转移数据。 |

**分盘监控（IDS）**  
- SSD 中转盘、归档盘、已启用的备份盘分别统计容量与使用率、分别告警。  
- 盘符/挂载变化、只读、离线：记告警，进程继续；恢复后自动恢复监控。  
- 提供查询接口：各存储角色、容量、使用率、是否在线。  
- SSD 超过配置上限：加速向归档迁移、抑制/限流新中转写入，并紧急告警。  

分级：接近阈值 = 预警；超过阈值 = 紧急，可通知上层管理接口。

### 4.6 SSD 高速中转（IDS）

1. 采集优先写 SSD 中转目录，再异步进入归档盘。  
2. 迁移成功后删除 SSD 对应临时；失败标记并重试；多次失败进入错误/审计列表。  
3. 中转不得压过采集磁盘体验；可限制并发与节奏。  
4. 超大文件可分片，避免内存占满。  
5. 异常断电或进程重启后，发现 SSD 残留未迁移文件并续迁。  
6. 中转水位上限可配；超限加速迁出、告警并限制新写入。  

---

### 4.7 备份管理（IDS）

1. 总开关与检查周期可配；**同一自然日全量备份至多完整成功一轮**。  
2. **本地 + NAS** 双路径：医疗模式默认可配置为双备份均可用才满足策略；工业模式允许仅本地。  
3. 备份包带时间戳，保持目录层级与必要元数据；过程有进度（总数、当前、百分比、当前文件）。  
4. 新备份成功后清理超期旧包，删除记审计。  
5. 单文件失败、NAS 短暂离线：记错误，尽量继续其余文件；后续周期可重试。  
6. 支持手动触发全量备份，记录操作者与范围。  
7. 可将指定备份恢复到指定位置；恢复全审计，恢复后宜可再做完整性校验。

### 4.8 日志与审计

| 编号 | 需求描述 |
|------|----------|
| R07017 | 所有清理操作（自动/手动）生成不可随意篡改的审计日志，至少：操作时间、触发方式、操作者（系统/用户）、清理范围、涉及患者 ID/检查 UID（若有）、数据总大小、操作结果；支持导出；保存期限满足法规/制度要求。 |

**补充（IDS）**  
- 运行日志：按日分割，可滚动保留（如近 7 天，可配）。  
- 审计日志：独立存放；医疗默认长期下限明确且可加严；**禁止普通清理任务删除审计日志**。  
- 覆盖：启动、监控、迁移、清理、备份、恢复、配置变更、管理访问、鉴权失败、异常。  
- 级别：常规、预警、错误、审计。  
- 目录不可写时告警，不崩溃。

### 4.9 业务元数据与管理接口

**元数据**  
- 受管文件可记录：类型、项目、唯一标识、索引/帧号、是否 NG、路径、采集时间、大小、中转与备份状态、分类标记与优先级等。  
- 入库失败可重试；短时不可用时不丢可恢复记录。  
- 支持按项目、时间、NG、文件 ID 等查询与批量导出。  

**管理接口**  
- 能力：磁盘状态、告警、手动备份/受控清理、配置更新、日志/审计导出、打开各业务目录等。  
- “打开目录”在 Windows/麒麟上打开配置的真实路径。  
- 医疗模式管理通道须加密（HTTPS）；接口鉴权；失败与越权记审计。  
- 配置变更记审计：谁、何时、改了哪些项（前后对比）。

### 4.10 配置管理与运行形态

1. 首次启动生成默认配置；缺字段补默认；格式错误明确提示，**暂停相关任务但不崩溃**。  
2. 可配置项至少：归档/SSD/备份路径、各盘告警阈值、各类留存天数、扫描间隔、备份开关、中转容量上限、管理端口、运行模式（医疗/工业）、清理优先级映射、终止条件等。  
3. 管理接口更新配置后尽快生效（用户感知“改完可用”）。  
4. 路径在 Windows、麒麟、NAS 下可配可访问；错误路径明确告警。  
5. 医疗/工业一键切换后加载该模式推荐策略，并提示医疗下哪些为强制项。  
6. 交付 Windows 与麒麟 x86/ARM 可运行包；默认无强制 GUI，后台运行；支持开机自启。  
7. 升级/重装不得无提示清空配置、审计与备份路径中的数据。

### 4.11 医疗场景专项

1. DICOM 等可解析格式：识别常见患者标识；院内归档原件留存；对外导出/跨机构前按策略脱敏或拦截未脱敏并告警。  
2. 科研等：可仅提供去标识数据。  
3. 归档与备份静态加密 + 密钥分离与轮换；重要影像完整性校验；迁移/备份/恢复失败则隔离告警。  
4. 管理账号分级；删除、改配置、导出明文等授权 + 高危二次确认。  
5. 医疗模式可强制本地 + NAS（或认可第二副本）；急诊/纠纷/诉讼及永久保留标记不得被自动清理删除。  
6. 向 NAS/外部传患者相关文件用加密通道；生产管理接口 HTTPS。  
7. （可选）对外发副本可追溯标识/水印，不影响法定归档原件合规时允许“仅对外发副本加水印”。  

---

### 4.12 工业视觉场景专项

1. 默认不强制患者级脱敏；可选产线/设备水印。  
2. 元数据绑定产线、设备、批次；按批次检索与导出。  
3. 强调 SSD 中转与磁盘预警，保障连续生产。  
4. 受控导出到可移动介质并记录操作者与范围。  
5. NAS 备份可关，允许仅本地备份。  

---

## 5 全局异常与连续性

1. 目录缺失可自动创建（权限允许时）；权限不足则告警，其它任务继续。  
2. 单盘或 NAS 故障只暂停相关任务；恢复后自动续跑。  
3. 单文件失败不影响整轮任务目标。  
4. 监控、清理、备份、管理接口故障隔离，主守护不因单模块失败退出。  
5. 元数据服务短时不可用时有缓冲与恢复后补写。

## 6 性能与容量（用户可感知）

| 项目 | 需求 |
|------|------|
| 与采集共存 | 清理/迁移/备份时，采集写入无明显周期性卡死 |
| 目录规模 | 支持单目录海量小文件与大图混合长期运行 |
| 日增量 | 支持每日数十 GB 量级中转与按日备份策略 |
| 资源 | 常驻内存与 CPU 可控，不拖垮同机采集软件 |
| 连续运行 | 7×24 稳定，无因本软件导致的系统性内存只增不降 |

具体数值可在合同中按工位硬件再约定。

## 7 安全需求总表

1. 最小权限：只管理配置的路径。  
2. 管理入口鉴权与审计。  
3. 医疗模式下传输与对外接口加密。  
4. 审计日志防普通清理误删。  
5. 不默认向公网上传业务数据。  
6. 配置与密钥与程序分离。

## 8 明确不在范围

- 不承担临床诊断、报告书写、完整 PACS/HIS/MES 业务。  
- 不替代医院等保测评、等保整改与第三方审计结论。  
- 不保证任意加密盘、未知私有格式的深度解析。  
- 不提供未授权的数据恢复或对抗性“去水印”能力。

## 9 验收标准（用户视角）

1. 连续运行约定时长（如 7 天）无崩溃、无因本软件导致采集持续丢帧。  
2. SSD 中转开启时，高并发写入下采图过程平稳可接受。  
3. 分盘水位到阈值出现对应级别告警，记录可查；剩余 &lt;5GB 时禁用采集且日志仍可写。  
4. 清理严格按 P3→P2→P1，P0 不被自动删除；终止条件（时间/容量）行为与配置一致。  
5. 过期清理、每日至多一次完整备份、旧备份清理与配置一致。  
6. 医疗模式：双备份策略、对外脱敏/拦截、加密与审计要求可演示通过。  
7. 断电或进程重启后，SSD 未完成迁移可续迁；不出现无策略全量重复备份打满磁盘。  
8. 删除、备份、恢复、配置变更、导出等关键动作均有可导出审计记录。  
9. Windows 与麒麟（x86/ARM）均可完成安装、自启与基本功能验收。  
10. 管理接口在鉴权下可完成状态查询与授权操作；越权被拒绝并留痕。  
11. 首次启用自动清理有不可跳过风险提示；手动清理有确认短语与进度/可中止。

## 10 假设与依赖

1. 操作系统账号与磁盘 ACL、NAS 权限由用户环境配置。  
2. 时间准确（NTP）影响“按日备份”“留存天数”正确性。  
3. DICOM 脱敏依赖可解析标准字段；私有封装需另行约定。  
4. 合规年限、是否必须双活机房等以用户制度与合同为准；本需求提供可配置能力支撑。

## 11 需求优先级建议

| 优先级 | 内容 |
|--------|------|
| **P0** | 数据分类与 P0–P3 映射；分盘监控告警（含 5GB 底线与禁采）；按策略清理（顺序+终止条件+采集保护）；SSD 中转与续迁；本地备份；运行/审计日志分离；基本配置与自启；Windows/麒麟可运行；手动清理确认与风险提示 |
| **P1** | NAS 备份与按日仅一次全量；元数据检索；管理接口鉴权；审计独立长期保留；医疗/工业模式切换；SMART/健康告警；密钥生命周期基础能力 |
| **P2** | 配置热更新体验；脱敏与导出拦截；完整性校验；加密算法增强与密钥轮换；水印/溯源；细粒度角色；HTTPS 强制；回收站保护期精细策略 |
